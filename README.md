
# FilmAPI M3 - inf25dw1g35

Repository to host the **FilmAPI M3** project developed for 'Desenvolvimento Web I', a 2nd year subject at UMAIA. Developed by Group 35 : [@FranciscoDias](https://github.com/franciscodias96).

## Short theme description

FilmAPI is a RESTful API designed to manage films, directors, genres and actors supporting full CRUD operations on database records.
The API is consumed by a **web backoffice client** built with **React-Admin**, enabling efficient management of the film database.

## Repository organization

*  **Backend** (Loopback 4) : [lb4filmapi folder](lb4filmapi/)
*  **Frontend** (React-admin) : [filmapi_react_app](filmapi_react_app/)

## Technologies

Technologies used in this assignment:
* [Javascript](https://developer.mozilla.org/en-US/docs/Learn/JavaScript) & [Typescript](https://www.typescriptlang.org/)
* [Loopback 4](https://loopback.io/index.html) – Code-first REST API development
* [MySQL](https://www.mysql.com/)– Relational database
* [React](https://react.dev/) & [React-admin](https://marmelab.com/react-admin/) – Backoffice web client
* [OpenAPI 3.0](https://swagger.io/specification/) – API documentation
* [Docker](https://www.docker.com/) – Multi-container deployment
* [Postman](https://www.postman.com/) – API testing
