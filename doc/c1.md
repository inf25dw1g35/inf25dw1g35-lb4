

# C1 : FilmAPI M3 - Loopback 4 API

## Description


This project consists of a **RESTful API for managing films, directors, genres amd actors**, developed using **LoopBack 4**, a **Node.js framework** for rapid API development.  
The API supports **full CRUD operations** (Create, Read, Update, Delete) and provides structured **JSON responses** for easy client consumption.

The project was developed as a practical assignment for the **Desenvolvimento Web I** course, illustrating:

-   **Code-first API development** with LoopBack 4
-   Client-server communication over HTTP with multiple methods (POST, GET, PATCH, PUT, DELETE)    
-   Structured JSON data representation   
-   OpenAPI 3.0 documentation for endpoints  
-   Multi-container deployment using Docker

The API is consumed by a **web backoffice client**, enabling efficient management of resources through a user-friendly interface.

### Key Features

-   REST API endpoints for managing **Films, Directors, Genres and Actors**

-   Relations between resources:

    -   **1:n** (e.g., Director → Films)    
    -   **m:n** (e.g., Films ↔ Actors)
        
-   Sample data prepared with 30 records per resource  
-   Filtering and querying via HTTP parameters
-   Modular project structure with separation of **models, controllers, and repositories**  
-   Dockerized setup for quick deployment of the API and MySQL database
