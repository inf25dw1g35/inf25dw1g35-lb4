

# C2: Resources

  

This section describes the **resources and endpoints** available in the **FilmAPI**.

The API allows managing **films, actors, directors, and genres**.

---  

## Films

**Film resources** allow creating, querying, updating, and deleting films.

**Main endpoints:**

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/films` | Lists all films |
| GET | `/films/{id}` | Retrieves a film by its ID |
| POST | `/films` | Creates a new film |
| PUT | `/films/{id}` | Updates an existing film |
| PATCH | `/films/{id}` | Updates an existing film partially |
| DELETE | `/films/{id}` | Deletes a film by ID |

**Example of a Film resource:**
```json
{
"id": 1,
"title": "Film 01",
"year": 1920,
"director_id": 1,
"genre_id": 1
}
`````

```json
{
````
